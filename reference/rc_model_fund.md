# Fundamental parameters for Rogers-Castro migration schedule

Set of fundamental parameters for the Rogers-Castro migration age
schedule, as suggested in Rogers and Castro (1981).

## Usage

``` r
rc_model_fund
```

## Format

A `tibble` with two columns and seven rows:

- param:

  Character string for the seven parameters

- value:

  Parameter values

## Source

Rogers, A., and L. J. Castro. (1981). Model Migration Schedules. *IIASA
Research Report 81* RR-81-30
